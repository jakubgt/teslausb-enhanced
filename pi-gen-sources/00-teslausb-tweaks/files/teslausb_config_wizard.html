TeslaUSB configuration wizard

Create the private teslausb_setup.json file for a Raspberry Pi Zero 2 W. This page works entirely on this computer.

1. Network and storage

Required ISO 3166-1 regulatory code. Use GB for the United Kingdom; no country is preselected.
Pi Zero 2 W cannot join a 5-GHz-only network.
Use the existing network password; it must be 8–63 UTF-8 bytes.
40G is recommended. Use a high-endurance microSD card of at least 64 GB; 128 GB or larger is preferred.
Use an IANA zone name. The network-dependent auto setting is intentionally not offered.

2. Recording archive

No off-device backup will be configured. You can configure an archive later.

3. Secure access

When supplied, password authentication is disabled. Private keys never belong here.

4. Review and download

The preview hides credentials. The downloaded file contains the real values. Keep it private, do not commit it, and remove unneeded copies from Downloads after placing it on the freshly flashed boot partition.
